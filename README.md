# Proyecto-Final-Electiva-CPC

Proyecto de limpieza y análisis de datos con Python, con preparación para aplicar técnicas de aprendizaje automático.

## Datos

El archivo seleccionado es `export.csv`, con registros de delitos de Los Ángeles. Está en la carpeta principal y ocupa aproximadamente 301 MB. `analisis.py` empieza revisando una muestra de 1,000 filas para no cargar todo el archivo en memoria. El análisis también admite Excel (`.xlsx` o `.xls`) si se cambia la ruta del archivo.

## Entorno

Instala las dependencias con `python -m pip install -r requirements.txt`.

Ejecuta el análisis inicial con `python analisis.py`.
